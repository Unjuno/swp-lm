# 公開リポジトリの取り扱い

- GitHub `Unjuno/swp-lm` は現在 **Public** です。公開ファイルは最小の研究コード、テスト、文書に限定しています。
- 1M/8M教師重み、学習済みチェックポイント、元の学習データやトークナイザー実体はGitHubに登録していません。
- V11〜V16の版別コード・ログ・報告書を含む元Git bundleは別途保管しています。このGitHubリポジトリには全132ファイルをまだ転送していません。
- PyTorch `torch.load` には信頼できる重みのみを渡し、可能なら `weights_only=True` を使用してください。
- データ再配布権限が確認されるまで、重みと生成データ本体は公開しない方針です。

## ローカルGit bundleからの追加反映

GitHub上のコミットとローカルbundleの履歴は別の初期コミットから始まります。手元で履歴を統合する場合は、差分を確認してから `--allow-unrelated-histories` で統合してください。`--force` による上書きは推奨しません。
