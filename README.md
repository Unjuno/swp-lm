# SWP-LM — 圧縮辞書・波形言語モデルの実験リポジトリ

**Status: experimental / not production-ready.**

このリポジトリは、ユーザー提供の1M/8M教師モデルを利用して実施したSWP-LM第11〜16次実験の**コードと検証結果**を整理したものです。固定フーリエ出力、PQコードブック、通常の低ランク出力、辞書更新、自然さ評価を比較します。

## 研究上の結論（暫定）

- PQ（Product Quantization）辞書によって**保存容量は削減**できた。ただし教師Embedding由来の固定情報を含むので、純粋なゼロからの学習とは異なる。
- **フーリエ基底の周期性に固有の性能上の優位性は未確認**。同規模のランダム基底で同程度または良好な結果があった。
- 辞書を学習可能にすると教師生成文に対する予測損失が改善する場合があるが、別分野英文では悪化する場合もあった。
- 自然さ評価では、特にgreedy生成で**反復や文脈逸脱**が発生した。生成文の自然さをPPLだけで代用できない。
- 使用した主な学習文書は**教師モデルが生成した人工データ**。汎用の言語能力、長文安定性、実コーパスでのスケーリング則は未検証。

## ディレクトリ

| パス | 内容 |
|---|---|
| `src/swp_lm/core.py` | PQ出力辞書／GRU学生の最小実装（第13次実験由来） |
| `tests/` | 合成データによる推論・確率正規化・勾配テスト |
| `examples/` | 教師・チェックポイント不要の最小動作例 |
| `experiments/v11`〜`v16` | 版ごとの研究コードとREADME（元アーカイブから選別） |
| `docs/EXPERIMENT_STATUS_JA.md` | 比較結果と解釈上の制約 |
| `scripts/restore_experiment_archives.py` | 元ZIPをローカルの `external/` に再展開する補助ツール |
| `external/` | 重みを含む元の版別環境（Gitには含めない） |

## 最短の動作確認

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
python -m pytest -q
python examples/synthetic_forward.py
```

学習済みチェックポイントを使った再評価は、元の実験ZIPと1M/8M教師ZIPが必要になる場合があります。必要な場合にだけ次を実行してください。

```bash
python scripts/restore_experiment_archives.py --input-dir /path/to/your/archives
```

**注意:** `experiments/v11`〜`v16` は版ごとの研究スクリプトを保管したものです。`external/` の重み、元の相対ディレクトリ構造がない場合、すべての実験スクリプトを直接実行できるわけではありません。各版の README を参照してください。

## 公開・再配布

このアーカイブには `1M(2).zip`、`8M.zip`、教師重み、生成データ本体、モデルチェックポイントを**収録していません**。学習済みモデルの再配布権限やデータのライセンスは別途確認してください。ユーザーによる明示的なライセンス選択がないため、オープンソースライセンスは設定していません。

研究上の数値は各版に記録された実験条件に依存します。新しいハードウェアやデータで同じ性能を保証するものではありません。
